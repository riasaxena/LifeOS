# Mockups

The clickable iOS mockups for LifeOS live in a Claude artifact rather than as
static files here, so they stay editable/interactive:

**https://claude.ai/artifact/7tuWyEE4KmrsbF38DiWKuJ**

9 screens, wired together as a real click-through prototype:

- **Home** — scrollable "Today" checklist (center tab)
- **Health** — today's meds + workout, with a streak banner
  - **Streak Detail** — longest streak, 30-day adherence, 4-week heatmap
- **Social** — rotating catch-up queue (Friends / Work)
  - **Add Person** — name, category, preferred contact method, cadence
- **Hobbies** — evening commute suggestion + hobby list
  - **Add Hobby** — name, status, commute-friendly toggle
- **Career Prep** — morning commute reading/podcast queue
  - **Add Item** — type, title, link, topic

Tab bar order (left to right): Health, Social, Home, Hobbies, Career Prep.
